# App per Mac – sito di supporto

Pagine di presentazione, supporto e privacy delle app macOS, pubblicate con GitHub Pages
su https://stefton71.github.io/apps/.

Per aggiungere un'app: crea una cartella (es. `nuova-app/`) con `index.html`, `privacy.html`
e `supporto.html` sul modello di `apri-p7m/`, e aggiungi una scheda in `index.html`.
