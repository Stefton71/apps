# App per Mac – sito di supporto

Pagine di presentazione, supporto e privacy delle app macOS, pubblicate con GitHub Pages
su https://stefton71.github.io/apps/.

Il sito è in cinque lingue (italiano, inglese, tedesco, francese, spagnolo): le pagine italiane sono
nella radice e in `apri-p7m/`, le altre in `<lingua>/` e `apri-p7m/<lingua>/`. Il menu 🌐 cambia lingua;
alla prima visita `assets/lingua.js` propone la lingua del browser e poi ricorda la scelta.

Le pagine si generano con `scripts/genera-sito.py` del progetto Apri P7M, che contiene tutti i testi:
modifica lì e rigenera, poi `git commit` e `git push` da questa cartella.
